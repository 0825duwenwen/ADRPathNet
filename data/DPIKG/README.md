# Verified original DPIKG data

Nine original files are included, byte-for-byte from the local PVKG ZIP.
PVKG_811_CauseTailADR is the historical engineering name of paper DPIKG.
See ../DATA_VERIFICATION.json for the paper provenance hash comparisons,
split counts, disjointness, candidate checks and file hashes.
Training and evaluation use this directory via --data-dir data/DPIKG.
No original data files need to be downloaded from the server.
The supervising research team provided the dataset and authorized public release
of the code and data.
